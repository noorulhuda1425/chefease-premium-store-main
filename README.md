# Kitchub Store — Smart Kitchen E-commerce Platform

Kitchub Store is a modern e-commerce web application built for selling kitchen tools and home essentials in Pakistan. The platform provides a complete online shopping experience with product browsing, category filtering, Google authentication, cart management, Cash on Delivery, delivery workflow, coupon system, admin dashboard, inventory management, and order tracking.

Live Website: https://www.kitchub.store

---

## Project Overview

Kitchub Store is designed as a premium kitchen products store where customers can explore cookware, choppers, utensils, blenders, knives, drinkware, baking tools, and other kitchen essentials. The goal of this project is to create a fast, responsive, user-friendly, and scalable online store with a professional admin management system.

The platform supports both customer-side shopping features and admin-side business management features, making it suitable for a real-world e-commerce business.

## Main Modules

### 1. Product Catalog

The product catalog displays all available kitchen products with category filters, pricing, ratings, discount badges, and product descriptions.

Example categories include:

- Cookware
- Choppers
- Kitchen Utensils
- Baking Tools
- Silicone Utensils
- Blenders
- Knives
- Drinkware
- Measurement Tools
- Garden Products

---

### 2. Cart and Checkout

Customers can add products to the cart, review their selected items, apply available coupons, and place orders using Cash on Delivery.

---

### 3. Authentication

The platform uses Supabase Authentication with Google OAuth, allowing users to sign in securely and manage their shopping activity.

---

### 4. Admin Dashboard

The admin dashboard provides tools to manage the complete store workflow, including products, orders, inventory, coupons, and delivery statuses.

---

### 5. Inventory Management

The inventory module helps track stock availability, prevent overselling, and keep product quantities updated from the admin panel.

---

### 6. Coupon System

Admins can create and manage discount coupons. Customers can apply valid coupons during checkout to receive discounts.

---

### 7. Order Management

Orders are stored in the database and can be managed from the admin dashboard. Admins can update order statuses such as pending, confirmed, shipped, delivered, or cancelled.
